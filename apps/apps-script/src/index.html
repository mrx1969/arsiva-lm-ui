Fitur belum dihubungkan

Unggah Drive belum aktif

Pada versi GAS ini tombol belum mengirim file. File nantinya diunggah langsung dari browser ke Shared Drive melalui endpoint Vercel agar stabil dan tidak membebani Apps Script.

  1. Shared Drive: buat folder induk Arsiva-LM dan salin Folder ID.
  2. Google Cloud: buat service account, aktifkan Drive API, lalu beri akses service account ke Shared Drive.
  3. Vercel: simpan credential dan Folder ID sebagai Environment Variables.
  4. Endpoint upload: Vercel membuat sesi resumable; browser mengirim file ke Drive; GAS memverifikasi file sebelum membuat Draft.
  5. Verifikasi petugas: petugas memeriksa Draft, kemudian menerima sebagai arsip Tersimpan atau mengembalikannya untuk revisi.

Tahap ini baru diperlukan saat frontend Vercel mulai dikerjakan. Sekarang tombol ini hanya menjelaskan dependensinya.
